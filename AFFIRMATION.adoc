== What this is, and how it works

`_pathroot` describes itself as a global marker-file protocol for modular
devtools environments. The tree holds:

* a Rust "Mustfile orchestrator" crate (`rust/mustfile-orchestrator`);
* a Zig FFI library (`ffi/zig`);
* Idris2 ABI sources (`src/abi`);
* three Ada libraries and an Ada TUI (`libs/ada-*`, `ada/tui`);
* a gated proof sweep (`verification/proofs`);
* RSR template validators (`scripts/`, `tests/`).

This file reports what those components' own build and check commands
produced at one commit. It is a receipt of runs, not a design document.

[[nuance]]
=== The honest nuance you must not lose

* "Proof sweep passes" means *gated modules compile and quarantined modules
  still fail*. Across the four provers, 3 modules are gated and pass. 6 are
  quarantined and fail: 5 Idris2 (`Types`, `ABI/Layout`, `ABI/Platform`,
  `ABI/Pointers`, `ABI/Compliance`) and the only Lean file,
  `ApiTypes.lean`. The MANIFEST records each of the 6 as never having
  compiled.
* The proofs under `verification/proofs` are generic RSR ABI and type
  templates. None states a property of the marker-file protocol.
* The Agda PASS needed a scratch `AGDA_DIR` listing Debian's
  standard-library 2.1. On this machine `~/.agda/libraries` points at a
  deleted job directory (`~/.claude/jobs/e5960853/tmp/agda-lib-defs/`), so
  any Agda check run as-is fails there. That is a fault in the machine, not
  the repo, and it was not modified.
* The Rust build passing is not a test result. The crate's 6 `#[test]`
  functions all live in the library, which does not compile under test.
  See <<outstanding>>.

[[outstanding]]
=== Outstanding / weak / refuted (no spin)

* *Rust library tests do not compile.* `cargo test --locked` exits 101.
  The error is `E0432 unresolved import crate::ProjectMetadata` at
  `src/executor.rs:134`; rustc suggests `crate::types::ProjectMetadata`.
  So 0 of the 6 `#[test]` functions run (types 1, executor 1, platform 2,
  parser 2).
* *Zig FFI does not build.*
** Under Zig 0.16.0, `zig build test` in `ffi/zig` exits 2: `build.zig:12`
   calls `addSharedLibrary`, which was removed from the build API.
** `.tool-versions` names `zig 0.14.0`, but only in a comment. Under
   0.14.0 both `zig build` and `zig build test` exit 1. The error is
   "documentation comments cannot be attached to tests" at
   `src/symlink.zig:61`.
* *Idris2 ABI sources do not typecheck.* `idris2 --check` on each of the 5
  files in `src/abi` exits 1.
** `Symlink.idr` and `SymlinkTypes.idr` fail with "Expected end of input"
   on a record field named `data` (a keyword).
** `Types.idr`, `Layout.idr` and `Foreign.idr` fail with "Expected
   namespaced name", because their module name is `_PATHROOT.ABI.*` and
   unfilled `{{TYPES}}` template text remains.
** No `.ipkg` covers `src/abi`.
* *Ada: 2 of 3 libraries and the TUI fail.*
** `path_environment.gpr`: exit 4, 3 errors (ambiguous call to `Append` at
   `path_environment.adb:106`).
** `symlink_manager.gpr`: exit 4, 2 errors. `Read_Symbolic_Link` and
   `Create_Symbolic_Link` are not declared in `GNAT.OS_Lib`.
** `ada/tui/pathroot_tui.gpr`: exit 4. Compilation succeeds, but binding
   fails with "Pathroot_Tui cannot be used as a main program".
** `alr` (Alire) was not on the restricted `PATH`, so the `alire.toml`
   manifests were not exercised.
* *Repo validators fail:*
** `bash tests/aspect_tests.sh`: exit 1, PASS=2 FAIL=1. All 4 hits are
   prose: 3 in `verification/proofs/README.adoc` lines 48–50 and the

** `bash tests/e2e.sh`: exit 1, PASS=0 FAIL=1. It clones the repo as an

** `bash scripts/check-no-placeholders.sh`: exit 1. 35 files contain

== Reproduce it yourself

Run these from a clean checkout of the anchor commit, with the toolchain
above on `PATH`.

[source,bash]
----
(cd rust/mustfile-orchestrator && cargo build --locked)   # exit 0
(cd rust/mustfile-orchestrator && cargo test --locked)    # exit 101, E0432
(cd ffi/zig && zig build test)          # 0.16.0: exit 2; 0.14.0: exit 1
for f in src/abi/*.idr; do idris2 --check "$f"; done      # each exit 1
for g in libs/ada-path-environment/path_environment.gpr \
         libs/ada-symlink-manager/symlink_manager.gpr \
         libs/ada-terminal-ansi/terminal_ansi.gpr \
         ada/tui/pathroot_tui.gpr; do gprbuild -p -P "$g"; done
                                        # exits 4, 4, 0, 4
for p in idris2 lean4 agda coq; do bash scripts/check-proofs.sh "$p"; done
                                        # each RESULT: PASS (Agda needs a
                                        # valid AGDA_DIR libraries file)
bash scripts/scan-dangerous.sh          # exit 0
bash scripts/test-shells.sh             # exit 0
just test                               # exit 1 by design
bash tests/aspect_tests.sh              # exit 1: PASS=2 FAIL=1
bash tests/e2e.sh                       # exit 1: unknown archetype
bash scripts/check-no-placeholders.sh   # exit 1: 35 files
bash scripts/validate-template.sh       # exit 1
bash scripts/check-root-shape.sh        # exit 1: 33 entries
----
